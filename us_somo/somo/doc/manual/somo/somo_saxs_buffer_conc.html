SOMO - SAS Data Utility: Solution Concentrations

Last updated: September 2026

The Solution Concentrations window (window title US-SOMO: SAXS Buffer: File Concentrations) is opened with the Concentrations button of the Data Utility module. It holds the concentration, in mg/ml, of every curve loaded in that module.

Concentrations matter in three places in the Data Utility:

  • in the PSV route to the buffer subtraction scaling factor, α = 1 − γ c ψ / 1000, where c is taken from this table;

  • in N (normalize) and Concentration normalized average, which are inactive until every selected curve has a non-zero concentration here;

  • in the Conc: field written into the header of each saved curve, and passed along with the curve when it is sent to the SAS module I(q) panel with the S button.

The table

The table has one row per curve, with the columns File and Concentration mg/ml. It is kept in step with the Data files list automatically: curves added to the module appear here, curves removed from it disappear, and curves produced by the module arrive with an appropriate value already filled in — the concentration of the solution for a buffer subtraction, the mean of the contributors for an average, and 1 for a normalized curve.

Curves assigned as the buffer or the blank with Set buffer and Set blank are excluded from the table, since a concentration has no meaning for them.

Concentrations found in the first line of a loaded .dat file, as a Conc:value keyword, are entered here automatically when the file is loaded, so a set of curves saved by US-SOMO or by any program writing that header carries its concentrations with it and needs no further work.

Values can be typed directly into the concentration cells. Clicking a column heading sorts the table on that column, alternating between ascending and descending order; clicking a row heading selects that whole row.

Buttons

  • Copy values, active when exactly one row is selected, takes the values of that row.

  • Paste values to selected writes the copied value into every selected row, and Paste values to all writes it into every row of the table. Between them these are the quickest way to fill in a series of exposures collected at one concentration.

  • Load reads concentrations from a file. Two cases are distinguished by the file extension:
    • a .sbc file — the format this window itself writes — is applied directly. Each line is read as a comma-separated pair of a curve name and a concentration, and rows whose first field matches a curve currently in the table are updated. Names that do not match anything are ignored, so a single .sbc file covering a whole session can be re-applied to any subset of it;

    • any other file is handed to the File Concentration Loader, which lets you say which of its columns holds the identifier and which holds the concentration before anything is applied. If no numeric rows can be found in the file at all, a warning is issued and nothing is loaded.

  • Save to file writes the table as a .sbc file, adding that extension if you do not supply it, and prompting before overwriting an existing file.

  • Save values commits the edited table back to the Data Utility and closes the window.

  • Cancel closes the window, discarding any edits made since the last Save values.

Unsaved edits

Values typed into this window take effect only once Save values has been pressed. If a buffer subtraction, a normalization or an average is started while edits are still pending, a warning points out that the concentrations used by the calculation differ from those displayed here, and recommends saving the values and repeating the calculation. The window can be left open alongside the Data Utility while you work.
