SOMO Automatic Guinier Range Search (guinier_search)

guinier_search finds the Guinier region of a scattering curve automatically and reports the radius of gyration Rg and the forward scattering I(0) with their uncertainties, the q range used, a quality score in [0,1], and diagnostics for aggregation or repulsive interactions. It is available from the headless command line (us_saxs_cmds_t), from the JSON run type used by pipelines, and from the SAS window through gui_script. Every parameter of the search can be set from all three entry points, so defaults can be changed without rebuilding the program. The routine is additive to the existing Guinier options "Search for best Guinier range" mode, which is unchanged.

Algorithm

  1. Cleaning. Non-finite points and points with q < 0 are dropped; points with I(q) ≤ 0 are dropped when dropneg is on (the default) or cause a failure otherwise; the optional hard limits qmin / qmax are applied; unsorted q is sorted with a warning. Standard deviations are used for weighting only when every SD in the curve is positive and finite (usesd auto); otherwise the fit is unweighted with a warning, and a noise floor sigfloor in ln I keeps noise-free theoretical curves from looking "significantly" curved.
  2. Preliminary Rg. For each starting point, the window is grown while its slope is either not yet significant or still satisfies q·Rg ≤ qrgmax. The longest valid window over all starts gives the preliminary Rg, so a short low-q upturn from aggregates (a valid Guinier region of a very large particle) loses to the particle itself. The search is then restricted to q ≤ regionfactor · qrgmax / Rg, which excludes spurious small-Rg fits to the high-q tail.
  3. Window enumeration. Every window in the region with minpts to maxpts points is fitted (ln I versus q2; ln qI or ln q2I for the cross-section and transverse types). A window is valid when the slope is negative and significant (|slope| / SD ≥ slopet), q·Rg at its end is at most qrgmax (optionally at most qrgmin at its start), its q·Rg span is at least minspan, and Rg lies within the optional rgmin / rgmax limits.
  4. Scoring. Each valid window receives seven terms in [0,1]: (1) 1 / reduced χ2 when above 1; (2) a curvature penalty from the t-statistic of a quadratic term (half at curvt); (3) the q·Rg span divided by qrgmax; (4) coverage of the available Guinier region (weight 0 by default); (5) a start penalty 1 / (1 + k/n) where k counts skipped low-q points that lie within skipz SDs of the line, i.e. points there was no reason to skip; (6) forward consistency: when the points beyond the window but inside q·Rg ≤ qrgmax deviate significantly (|z| > fwdz), a penalty of half at a mean deviation fwddev in ln I; (7) consensus, a Gaussian in the relative distance of the window's Rg from the quality weighted median Rg of all windows, width constol. The quality is the weighted geometric mean of the terms with exponents weights; the window of highest quality is reported.
  5. Results. Rg and I(0) with SDs (inflated by the square root of the reduced χ2 when it exceeds 1), the first and last point of the window (1-based, in the original file), the number of points used, skipped, dropped and removed, the q and q·Rg range, the reduced χ2, the curvature t-statistic, the quality, and the mean and spread of Rg over the top topfrac of windows. Optional outlier rejection (outlier > 0) removes points of the chosen window deviating by more than that many SDs and refits.
  6. Low-q diagnostics. The skipped points and the first third of the window are compared with the line fitted to the rest of the window. A z-score above aggthresh with a mean deviation above aggmindev in ln I flags a low-q upturn (aggregation, or an intrinsically convex Guinier plot such as an elongated particle or a flexible chain); the mirror case flags a downturn (repulsion, interparticle interference). These are advisory: a single curve cannot separate aggregation from shape.

Command line

us_saxs_cmds_t guinier_search [--json|--csv] [--key value ...] file ...

Prints one table line per file (default), one JSON object per line (--json) or one CSV row per file (--csv). Input files may be whitespace or comma separated text with two (q, I) or three (q, I, SD) numeric columns; lines that do not start with two numbers are ignored, so headers and footers need not be removed. Example: 

us_saxs_cmds_t guinier_search --minpts 12 --qrgmax 1.0 sample1.dat sample2.dat

JSON run type

us_saxs_cmds_t json '{"guinier_search":1,"files":["a.dat","b.dat"],"minpts":12}'
us_saxs_cmds_t json '{"guinier_search":1,"name":"curve","q":[...],"i":[...],"e":[...]}'

The reply carries results, an array with one object per curve (ok, rg, rg_sd, i0, i0_sd, first, last, npts, qmin, qmax, qrgmin, qrgmax, chi2_red, curv_t, quality, lowq_z, lowq_dev, aggregation, repulsion, rg_spread_*, warnings, and errormsg when ok is false), nok (the number of curves analyzed) and params (the effective parameters).

Guinier options window

The checkbox Robust automatic Guinier range search in the Guinier options window routes the SAS window's Process Guinier, Process CS Guinier and Process TV Guinier buttons through this search, taking the q limits, the minimum and maximum number of points, the q·R limit of the respective type and the SD weighting choice from that window; the remaining parameters keep their defaults. The quality, the number of windows examined and the low-q diagnostics appear in the message area, and the csv output records "Robust automatic range fitting used".

gui_script

sas open
sas load_iq <file> [<file> ...]
sas guinier_search [csv <file>] [key value ...]
sas guinier [rg|cs|tv]
global guinier_robust_search 1

sas guinier presses the corresponding Process Guinier button, honouring the Guinier options; with global guinier_robust_search 1 beforehand it uses this search.

sas load_iq loads curves into the SAS window without scaling; sas guinier_search runs the search on every loaded curve, writes the table to standard output and the SAS window editor, and optionally a CSV file with all result fields.

Notes

  • For globular particles the Guinier approximation up to q·Rg = 1.3 is biased by one to three percent; precise data lead the search to shorter windows and smaller bias. For elongated particles and flexible chains set qrgmax to about 1.0 or lower.
  • When the measured Guinier region holds fewer than minpts points the routine fails with a message giving the number of available points instead of returning a value from outside the region; lower minpts deliberately if that is acceptable.
  • Data in nm-1 produce a warning when the maximum q exceeds 2; use qscale 0.1.
