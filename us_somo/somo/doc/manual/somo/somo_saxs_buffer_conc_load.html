SOMO - SAS Data Utility: File Concentration Loader

Last updated: September 2026

The File Concentration Loader (window title US-SOMO: SAXS Buffer: File Concentration Loader) is reached from the Load button of the Solution Concentrations window, whenever the file chosen there is not a .sbc file written by US-SOMO itself.

Its purpose is to take an arbitrary tabular file — a concentration log from a chromatography system, a spreadsheet export, a table typed up by hand — and work out which of its columns identifies the measurement and which holds the concentration, so that the values can be matched onto the curves currently loaded in the Data Utility.

How the file is read

The file is split into fields on commas and/or whitespace. Only rows in which every field is numeric are retained; all others — titles, column headings, units, comments, trailing notes — are discarded automatically, so most instrument logs can be used without editing. If nothing numeric is found at all, the loader does not open and the Solution Concentrations window reports that the file does not appear to contain data the program understands.

What survives is displayed as a table, which is what you then work on.

Preparing the table

  • Clicking a column heading selects that whole column; clicking Delete Rows removes the rows currently selected. Use this to drop calibration lines, blanks, or a trailing block belonging to a different run. The window resizes itself to the remaining table.

  • Set column for frame timecode designates the selected column as the one that identifies each measurement — a frame number, a timecode, or any other integer that also appears in the names of your curves. The chosen column number is shown beside the button.

  • Set column for concentration designates the selected column as the one holding the concentration in mg/ml, again reporting the chosen column number beside the button.

  • Adjust frame timecode asks for an integer correction between −1000 and +1000 and adds it to every timecode. This is for the common case where the concentration log and the scattering frames are numbered from different origins, or are offset by a fixed number of frames.

Matching and applying

Trial set performs the match without committing it. Each curve name in the Data Utility is broken into its runs of digits, and those numbers are compared — last one first — against the timecode column of the table. The first number that matches supplies the concentration for that curve. Working from the end of the name is deliberate: it picks up the frame index in names such as lysozyme_2024_0137 in preference to the year.

The result is reported beside the button as Match ok or No matches found, together with the count of curves matched and not matched. Always run Trial set and check those counts before saving — a wrong column designation or a missing timecode offset shows up immediately as a low match count, whereas once the values are applied it can be hard to notice that a subset of the curves kept their old concentrations.

Save values applies the trial match to the Solution Concentrations table and closes the loader. Curves that were not matched keep whatever concentration they already had. Cancel closes the loader without changing anything.

Remember that the concentrations then still have to be committed from the Solution Concentrations window with its Save values button before any calculation will use them.

Saving the result for re-use

Once a set of concentrations has been matched successfully, use Save to file in the Solution Concentrations window to write it as a .sbc file. That file is keyed on the curve names rather than on timecodes and is applied directly on loading, so the column mapping and the timecode adjustment only ever have to be done once per data set.
