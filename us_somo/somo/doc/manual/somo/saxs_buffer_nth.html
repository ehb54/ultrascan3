SOMO - SAS Data Utility: Select curves

Last updated: September 2026

The Select curves dialog (window title US-SOMO: SAXS Data Utility : Select curves) is opened with the Select button of the Data Utility module, and becomes available once more than two curves are loaded. It exists for the case where the Data files list holds too many curves for clicking through them to be practical — a long series of exposures, or the output of a parameter scan — and provides three ways of picking a subset, together with a preview plot for deciding which subset you want.

The left of the dialog shows the Complete list of data files and, beside it, the Selected data files that the current criteria produce, with a running count below them. Nothing is applied to the main window until you say so, so the criteria can be tried freely.

The three selection methods appear under the headings Select every Nth over range, Select by name and Select by intensity. Clicking a heading collapses or expands that section, so only the method in use need be on screen; which section is open is remembered for the next time the dialog is opened. The list of files can be collapsed the same way.

Each method offers the same pair of buttons: Select Only replaces the current selection with the matching curves, while Select Additionally adds them to what is already selected. Applying several methods in succession with Select Additionally is the way to build up a compound selection.

Select every Nth over range

  • Select every Nth is the stride, default 1.

  • Starting curve offset and Ending curve offset are positions in the Data files list, counted from 1. The name of the curve at each offset is displayed beside the field, so you can see what you are pointing at without counting.

Starting from the start offset, every Nth curve up to and including the end offset is selected. With a stride of 1 this is simply a contiguous block. This is the tool for thinning a long series down to a manageable, evenly spaced sample before plotting, or for picking out one exposure per repeat in an interleaved measurement.

Select by name

Name contains selects every curve whose name contains the given text as a substring. The comparison is a plain substring match, not a regular expression, and it is case sensitive. The text you used is remembered between openings of the dialog.

To load files by pattern rather than select among those already loaded, use the RL regular expression loader or the Similar button in the main Data Utility window instead.

Select by intensity

This method selects on the total integrated intensity of each curve — the sum of I(q) over its points — which is a convenient proxy for how much material was in the beam. It is the practical way to separate the exposures at the top of a peak from those on the baseline, or to find frames damaged by a beam or sample problem.

  • Checking q range [A] restricts the sum to the given interval, defaults 0 to 5 A-1; unchecked, the whole curve is used. Restricting to the low-q region usually gives the cleanest discrimination.

  • Compute average intensity of all and Compute average intensity of selected compute the total intensity of every curve in the respective set and report the minimum, maximum and mean in the text area. Each computation also adds a curve to the plot on the right, of total intensity against the leading number in the curve name — effectively an elution or kinetic profile of the series. Repeated computations, for instance over different q ranges, accumulate as separate curves for comparison.

  • The threshold is set in the field beside the Above / Below intensity level [A.U.] radio buttons, and is drawn on the plot as a red horizontal marker. The wheel below the plot is bound to it and spans the observed intensity range, so the marker can be dragged through the profile until it sits where you want the cut.

  • Select Only and Select Additionally then act on the curves above, or below, that level.

The plot has its own controls: Clear removes the accumulated curves, Rotate colors cycles the colors when two of them are hard to tell apart, and Save .DAT asks for a directory and writes each plotted profile to it as a two-column t, I(t) file, named after the first contributing curve with the q range appended.

Applying the selection

  • Select in main window applies the current selection to the Data files list and leaves the dialog open, so you can look at the result and refine the criteria.

  • Select in main window and exit applies it and closes the dialog.

  • Quit closes the dialog without changing the selection in the main window.
